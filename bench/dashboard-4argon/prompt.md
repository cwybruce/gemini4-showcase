# 任务 C：个人健康数据仪表盘 — 提示词与测试记录

- 模型：浏览器版 Gemini 4（4 Argon），思考等级：高点（超级详尽）
- 日期：2026-10-14
- **结论：成功** —— 前三次尝试失败（见下），第四次用新方法论（简洁提示词 + 要求 html 围栏 + 代码块下载按钮）一次成功，`index.html` 已入库。

## 原始提示词

```
你是资深前端工程师。直接输出一个完整、可保存为 .html 双击打开的单文件网页代码：不要任何解释、不要 markdown 代码围栏、不要开头结尾的寒暄。硬性要求：①零外部依赖（不引用任何 CDN、在线字体、图片，所有资源内联）；②中文界面；③桌面与移动端都可用；④代码完整可运行。

任务：做一个个人健康数据仪表盘。包含 7 天步数柱状图、睡眠时长折线图、本周运动时长环形图，全部用原生 SVG/Canvas 手写（不许用任何图表库），配数据卡片，深色科技风。
```

## 尝试记录

- **第 1 次**：原提示词。模型生成极其铺张（CSS 约 20KB，含 topbar / KPI 卡片 / 图表网格 / 环形图 / ECG 监护 / insights / tooltip / modal / 响应式断点），明显将超出单次回复长度上限，**主动停止**，未等截断。
- **第 2 次**：新对话，原提示词 + 精简句（"注意：代码务必精简紧凑，确保整个 HTML 在一次回复内完整输出，不要超出长度限制。"）。生成显示完成，但复制提取只拿到从 `<div class="card col-5">` 开始的半截片段，无法获得可验证的完整 HTML，不予采用。
- **补救**：回到第 2 次对话，要求模型把已生成内容原样分两段重发。第一段（`<!DOCTYPE html>` → `</style>`）成功取回；第二段模型未按要求输出（给了从 `<div class="card col-5">` 开始的残缺片段，缺 `<body>` 开头、`<script>` 与 `</html>`）。按既定规则放弃，不编造补全。
- **第 4 次（成功）**：用户要求重做。改用新方法论——简洁提示词（删掉"不要 markdown 围栏"，改为"用 html 代码块输出"，不加任何自创附加要求）：
  ```
  你是资深前端工程师。做一个个人健康数据仪表盘：7 天步数柱状图、睡眠时长折线图、本周运动时长环形图，全部用原生 SVG/Canvas 手写（不许用任何图表库），配数据卡片，深色科技风。单文件 HTML、零外部依赖、中文、桌面与移动端可用。用 html 代码块输出。
  ```
  对话：https://gemini.google.com/app/2fa0b9b777edba69 ，约 12 分钟生成。回答渲染为代码块，点右上角"下载代码"按钮一次拿到完整文件：46,624 字节，以 `<!DOCTYPE html>` 开头、`</body></html>` 结尾，零外部依赖。页面：AETHER BIO-METRICS 深色科技风，4 张数据卡片 + 7 天步数柱状图 + 本周运动环形图 + 睡眠监测，均为原生 SVG/JS 手写。
